SteamNative is a shortcut to open steam without having to open crossover

Why using SteamNative 
Steam natively on Mac Os dissapoints you, you use crossover instead, but why not try to make windows steam look like the native one not having to open CrossOver

REQUIRES
allow SteamNative everything and give it SystemEvents.app And Accesability and Automation


What it does 
it opens steam.exe through wine/crossover but not opens it great for people who want to play Windows games on mac without emulaters
